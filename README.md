# Sisrose-video-emas-
Projek video emas Umar Jewelleries menggunakan Claude AI

## SIS ROSE Pink Luxury Signature Outro

- `outro/SIS_ROSE_PINK_LUXURY_OUTRO.mp4`: the saved master outro (1080×1920, 30 fps, 4.0 s, sounds: WHOOSH → POP → CLICK → DING).
- `outro/build_outro.py`: the editable master template. It renders the same outro again from `outro/assets/` (original photo plus fonts).
- `append_outro.sh`: adds the saved outro, unchanged, to the end of a video:

```bash
./append_outro.sh my_video.mp4            # -> my_video_WITH_OUTRO.mp4
```

Fonts: Cinzel Bold, Poppins SemiBold and Montserrat ExtraBold (SIL Open Font License, from Google Fonts / Fontsource).
All sound effects are generated by the script itself, so they are original.
